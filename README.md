# Princess Day Bestie Website 👑💗

A cute, animated Princess Day greeting website with a fairytale countdown reveal, floating hearts and sparkles, a surprise message, and the uploaded background song.

## Deploy with GitHub Pages

1. Create a new repository on GitHub (for example, `princess-day-bestie`).
2. Upload **all** files and folders from this project. Keep `index.html` and the `assets` folder at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch **main** and folder **/(root)**, then click **Save**.
6. Wait for GitHub Pages to publish. Your public website URL will look like:
   `https://YOUR-USERNAME.github.io/princess-day-bestie/`

## Local preview

Open `index.html` in a browser. Keep the `assets` folder beside it so the song can load.

## Notes

- The song starts only after the visitor taps the Play button (browser autoplay restrictions).
- The website is static HTML/CSS/JavaScript; no build tools or framework installation are required.
